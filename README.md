# Universal Scene Description

## Introdution

Universal Scene Description (USD) is an efficient, scalable system for
authoring, reading, and streaming time-sampled scene description for
interchange between graphics applications.

For more details, please visit the web site [here](http://openusd.org).

**Note:** This repository is not the official OpenUSD repository. Its primary focus is to explore the integration of knowledge graphs, LLMs and other generative AI technologies into the management and authoring of graphics assets within the OpenUSD framework. For the original implementation and official development, please refer to the [official OpenUSD repository](https://github.com/PixarAnimationStudios/OpenUSD).
